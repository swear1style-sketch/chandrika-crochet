# Chandrika • Artist | Fine Crochet & Fiber Art Atelier

A premium, artisanal website for **Chandrika**, an independent crochet artist and freelancer based in the mountains of Himachal Pradesh, India. Handcrafted to showcase her signature micro-botanical gilded frames, collectible amigurumi action figures, forever rose bouquets, and scenic Himalayan relief tapestries.

---

## 🌟 Brand & Atelier Highlights
- **Direct WhatsApp Ordering**: Patrons and collectors can click any product or custom order button to be redirected directly to WhatsApp (**+91 98487 59103**) with pre-filled order specifications.
- **100% Authentic Crochet Imagery**: Features high-resolution crops from Chandrika's original mountain cabin yarn relief tapestry, real micro-crochet flora in antique baroque frames, and poseable fiber sculptures.
- **Bespoke Commission Studio**: Interactive 4-step configurator for custom sizes, frames, color palettes, and reference details.
- **Himachal Heritage**: Celebrates the patience of slow living and single-needle fiber art in Himachal Pradesh.

---

## 🚀 Tech Stack
- **Framework**: React 18
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS
- **Icons**: Lucide React & Custom Brand SVGs
- **Typography**: Cormorant Garamond, Cinzel, Plus Jakarta Sans

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/swear1style-sketch/kroshe.git

# Navigate to directory
cd kroshe

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
